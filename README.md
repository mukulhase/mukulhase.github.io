# mukulhase.com

The source for Mukul Hase's personal website, built with React, TypeScript, and Vite and published through GitHub Pages.

## Development

```sh
npm install
npm start
```

## Checks

```sh
npm test
npm run build
```

## Deployment

`npm run deploy` builds the site and publishes `dist/` to the `gh-pages` branch. The custom-domain file in `public/CNAME` is copied into every build so the site remains available at `mukulhase.com`.
